# Manual de Supervivencia en Camping

## Descripción
Este proyecto es una página web desarrollada en HTML que muestra información básica sobre cómo sobrevivir en un entorno de camping.

## Contenido
- Equipo necesario
- Pasos de supervivencia
- Tabla de elementos
- Formulario de contacto
