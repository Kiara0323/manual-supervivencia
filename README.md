# Manual de Supervivencia en Camping

## Descripción
Este proyecto es una página web desarrollada como trabajo integrador de Programación III. Presenta información básica sobre cómo sobrevivir en un entorno de camping e incorpora funcionalidades interactivas desarrolladas con JavaScript.

## Contenido
- Equipo necesario
- Pasos de supervivencia
- Tabla de elementos
- Formulario de contacto
- Video sobre supervivencia en camping (iframe)
- Enlace externo con información adicional

## Funcionalidades implementadas
- Menú de navegación con enlaces internos.
- Diseño responsive para celulares y tablets.
- Imagen ilustrativa sobre camping.
- Video incrustado mediante iframe.
- Enlace externo a información sobre supervivencia.
- Tabla con elementos y sus usos.
- Formulario con validación usando JavaScript.
- Lista interactiva de consejos utilizando un array.
- Vista previa del consejo mientras el usuario escribe.
- Validación del formulario mediante `try...catch.`
